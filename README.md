# Онлайн-магазин кондитерских изделий

Дипломный проект - интернет-магазин тортов, пирожных, конфет и подарочных наборов.

**Стек:** Python 3.11+, Django 5.2, PostgreSQL, собственный CSS (без Bootstrap и тяжёлых JS-фреймворков).

---

## Запуск локально

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Hanabiiiko/confectionery-shop-django
cd confectionery-shop-django
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Создать базу данных в pgAdmin

Открыть pgAdmin -> правой кнопкой на «Databases» -> «Create» -> «Database».  
Имя базы данных: `confectionery`.

### 4. Настроить переменные окружения

```bash
cp .env.example .env
```

Открыть `.env` и заполнить значения:

```
SECRET_KEY=сгенерируйте-случайный-ключ
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
DB_NAME=confectionery
DB_USER=postgres
DB_PASSWORD=ваш-пароль
DB_HOST=localhost
DB_PORT=5432
```

### 5. Применить миграции

```bash
python manage.py migrate
```

### 6. Создать суперпользователя

```bash
python manage.py createsuperuser
```

Суперпользователь получает доступ к Django Admin (`/admin/`). Чтобы он мог работать с панелью менеджера (`/dashboard/`), дополнительно назначьте ему роль менеджера (см. раздел «Роли» ниже).

### 7. Заполнить тестовыми данными

```bash
python manage.py seed_data
```

Команда создаёт 5 категорий и 20 товаров. Безопасно запускать повторно — дубликаты не создаются.

### 8. Запустить сервер

```bash
python manage.py runserver
```

Сайт доступен по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)

## Роли пользователей

| Роль | Возможности |
|---|---|
| **Покупатель** | Регистрация, вход, каталог, корзина, оформление заказов, отзывы, избранное, история заказов, личный кабинет |
| **Менеджер** | Всё, что доступно покупателю, плюс панель управления `/dashboard/`: CRUD товаров и категорий, управление заказами и задачами, промокоды |

### Как назначить менеджера

**Через Django Admin** (`/admin/`):  
Найти пользователя -> установить флажок «Is manager» -> сохранить.

## Структура приложений

```
confectionery-shop-django/
├── config/       — настройки проекта, корневые URL
├── accounts/     — кастомная модель пользователя (вход по email), профиль
├── shop/         — категории, товары, отзывы, избранное
├── cart/         — корзина на сессиях (без модели в БД)
├── orders/       — оформление заказов, mock-оплата, промокоды
├── dashboard/    — панель менеджера (CRUD товаров, заказы, задачи, промокоды)
├── templates/    — HTML-шаблоны
└── static/       — CSS, JS, изображения
```
